安全提醒

Token 凭据只在私聊中使用，绝对不要发到群里。
绑定二维码可以在群里获取，但请只扫自己发出的二维码。
所有指令都必须以 / 开头。
指令前缀可互换：zmd = ef = 终末地　｜　mrfz = 方舟 = 明日方舟　｜　skl = skd = 森空岛
例如 /ef开盒 和 /zmd开盒 效果相同，/方舟签到 和 /mrfz签到 效果相同

账号绑定与管理

/skl绑定扫二维码绑定（同 /skl扫码）否群聊、私聊均可
/skltoken绑定 凭据用 Token 凭据绑定账号否只能私聊，切勿发到群里
/skl角色更新刷新已绑定的游戏角色否新绑定或角色有变化时使用
/skl解绑解绑自己的森空岛账号否会删除角色和抽卡记录，需回复「确认」

终末地

/zmd开盒查看终末地角色卡是加 @用户 可查看群友
/zmd开盒 all展示全部终末地角色是all 要写在 @用户 前面
/zmd账号详情全部干员的练度详情图是含武器、技能等级和装备
/zmd签到手动为自己的角色签到否每天 00:20 已自动签到
/zmd签到详情查看自己的签到状态否只能查询自己
/zmd抽卡记录查看已保存的抽卡记录否每天 01:00 自动更新
/zmd抽卡记录更新立即拉取最新抽卡记录否想马上看到新记录时使用
/zmd导入小黑盒 小黑盒ID从小黑盒补回更早的抽卡记录否只能导入与自己绑定 UID 相同的小黑盒账号；撤回发 /zmd撤销小黑盒导入
/zmd欧非榜本群终末地抽卡欧非排行否仅群聊；发 /zmd欧非榜 退出 可不上榜

终末地资料库数据来自 AKEData，有新版本时自动通知

/干员名查看干员资料图—支持昵称：/提丰 /plk /小庄
/干员名专武查看该干员专武资料图—例：/提丰专武
/武器名查看武器资料图—支持简称：/寒夜幽影 /寒夜

高难关卡战争回响 / 影拓丰碑

/战争回响本周轮换的三个关卡—显示剩余时间
/影拓丰碑全部系列和关卡名—苦难模式全通即可镀层
/攻略 关卡名 难度机制、敌人、本群通关阵容、推荐视频—例：/攻略 重伤之围 残酷
/竞速榜竞速榜目录，引导到回响 / 丰碑竞速—记不清关卡名就从这里进
/回响竞速 关卡名战争回响本群最快通关排名—不带关卡名显示本周全部关卡
/丰碑竞速 丰碑名影拓丰碑本群最快通关排名—不带参数列出全部丰碑；也可写单关名
/榜单角色出场率全部绑定玩家的高难干员出场率（不分群）—可加 关卡名 / 战争回响 / 影拓丰碑
/攻略统计 退出不参与阵容统计和竞速榜—重新加入发 /攻略统计 加入
